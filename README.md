# BreathCare Suite

# PROJECT

Breath Care Kart - Inventory & Invoice Management System

## OBJECTIVE

Design and build a complete multi-page SaaS web application for a medical equipment rental company.

This is NOT a landing page.

This is a production-ready internal dashboard application.

The application must feel like Linear, Stripe Dashboard, Notion, Vercel Dashboard, and Framer.

Design should be premium, minimal, modern, clean, fast, and highly professional.
